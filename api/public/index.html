Search LinkedIn posts and react to them, through one API.

Connect your LinkedIn account once via the browser extension, then call a clean REST API for keyword post search and post reactions — governed and paced so your account stays healthy.

How it works

1. Create an account and grab your API key from the dashboard.
2. Download the connector extension and log into LinkedIn as you normally do.
3. Click "Connect this account" in the extension popup.
4. Call the API with your key. See the docs.

Why not just scrape it yourself

Every request is paced by a rate governor, runs with a real Chrome TLS fingerprint, and halts automatically the moment LinkedIn shows a warning sign — instead of retrying into a ban. Full request audit log included.
